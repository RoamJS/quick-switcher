**Jump to saved pages and blocks from a searchable switcher and command palette workflows built for fast graph navigation.**

[![Ask DeepWiki](https://deepwiki.com/badge.svg)](https://deepwiki.com/RoamJS/quick-switcher)

## Features

- Save frequently used pages and blocks as Quick Switcher entries.
- Open saved pages and blocks from a focused searchable dialog.
- Add entries from a single Roam settings input that searches pages and blocks.
- Optionally expose saved entries as command palette commands with a custom `QS: ` prefix.
- Remove saved entries from extension settings.
