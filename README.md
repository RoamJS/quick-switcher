**Jump to saved Roam pages and blocks from a fast, searchable switcher with optional command palette shortcuts.**

[![Ask DeepWiki](https://deepwiki.com/badge.svg)](https://deepwiki.com/RoamJS/quick-switcher)

## Features

- Save frequently used pages and blocks as Quick Switcher entries.
- Open saved pages and blocks from a Roam-style searchable dialog.
- Switch between `Open` and `Manage` modes inside the Quick Switcher dialog.
- Search Roam pages and blocks in `Manage` mode to add new saved entries.
- Review, delete, and alias saved entries from `Manage` mode.
- Search saved entries by alias, original title, or URL.
- Open saved entries in the main window, or open them in the right sidebar with `Shift+Enter`, `Shift`-click, or the `Open in sidebar` footer action.
- Optionally expose saved entries as command palette commands with a custom `QS: ` prefix. Aliased entries include both names, like `Alias (Original title)`.

## Settings

- `Open Dialog`: opens the Quick Switcher in `Open` mode.
- `Manage Saved Entries`: opens the Quick Switcher in `Manage` mode.
- `Add Saved Entries To Command Palette`: creates one command palette command per saved entry.
- `Command Palette Prefix`: customizes the prefix used for saved-entry command palette commands.
